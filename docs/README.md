## Dual-Track Governance

Project Phoenix operates **Engineering Track** + **Research Track (NRI)** under one Constitution ([ADR-0162](decisions/ADR-0162-dual-track-governance.md); [playbook](project/DUAL_TRACK_GOVERNANCE.md)). Research does not edit Constitution, Blueprint, Kernel, or Runtime; promotion is the only legal bridge.
