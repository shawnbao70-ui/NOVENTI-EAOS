# BOOK08 — 市场宪法

**仓库：** `NOVENTI-EAOS`  
**版本：** EAOS Charter v2.1  
**状态：** 生效  
**注意：** 市场商业化策略需人类批准。

---

## 标题

市场宪法

## 目的

确立 Marketplace、包分发、权限声明与生态治理的宪政原则。

## 范围

市场宪政。对齐 Package 蓝图与 PHX-M16。

## 当前状态

**规范正文生效**

## 未来扩展

上架评审、分成与争议解决（商业/法务批准后）。

---

## 核心条款

1. 市场包必须声明所需权限、事件契约与数据访问范围。  
2. 包不得分叉 Kernel，不得绕过租户隔离。  
3. 安装/升级/卸载必须可审计，并可回滚。  
4. 平台对市场保持中立治理，防止滥用与欺诈。  
5. 商业条款变更属商业决策，需人类批准。  
6. 行业包与 AI 包同等服从安全与 AI 治理宪法。  
7. Smart Terminal extension 必须签名、声明能力、在沙箱中运行、可撤销与回滚，且不得隐藏权限、审批、租户或审计控制。
