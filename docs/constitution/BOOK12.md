# BOOK12 — UI/UX 宪法

**仓库：** `NOVENTI-EAOS`  
**版本：** EAOS Charter v2.1  
**状态：** 生效  
**注意：** 重大 UI/UX 产品方向需人类批准。

---

## 标题

UI/UX 宪法

## 目的

确立操作体验、人机协作、无障碍与 UI 扩展边界。

## 范围

体验宪政。UI 不是业务规则宿主。

## 当前状态

**规范正文生效**

## 未来扩展

设计系统与无障碍验收标准（UX 批准后）。

---

## 核心条款

1. UI 仅消费 API/Kernel 能力，不承载业务真相。  
2. 重要行为必须对操作者可见（Transparency）。  
3. AI 协作界面必须展示权限范围与审批状态。  
4. 包 UI 不得破坏租户与权限边界。  
5. 重大品牌/信息架构变更需人类批准。  
6. 无障碍与多语言属于全球运营基线能力。  
7. BOOK12 规定体验与设计基线；涉及会话、意图、命令、Commit、AI 协作治理与 extension sandbox 的交互必须服从 BOOK23。
