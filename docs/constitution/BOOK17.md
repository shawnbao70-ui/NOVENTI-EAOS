## 标题

AI Agent 宪法

## 目的

确立智能体能力、工具使用、记忆、规划执行与问责边界。

## 范围

Agent 宪政。对齐 AI Runtime 接口大纲。

## 当前状态

**规范正文生效**

## 未来扩展

工具白名单分级与 Agent 生命周期状态机。

---

## 核心条款

1. Agent 必须具备稳定技术身份。  
2. Agent 工具调用必须经权限求值。  
3. Agent 记忆分层管理，受保留与权限约束。  
4. Agent 规划可自动；高影响执行需批准。  
5. Agent 不得篡改审计记录。  
6. Agent 不得跨租户行动。  
7. Agent 必须在 AI Runtime 内运行。  
8. Agent 命名遵循平台命名标准。  
9. Agent 是 AI Runtime 内的技术执行单元，不等同于 AI Employee、Digital Human、AI Assistant 或 Smart Terminal。  
10. Agent 通过 Smart Terminal 参与交互时，权限、审批与执行状态必须被准确呈现，终端不得扩大 Agent 权限。  
11. Agent 动作同时属于高影响、高风险或商业敏感时，依 BOOK22 适用最严格控制。
