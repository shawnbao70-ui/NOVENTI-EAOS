# ADR-0418 — Package Surface ↔ Terminal Resolve Alignment

**状态：** Accepted（PHX-G398）  
**日期：** 2026-07-27  

## 决策

1. Package status 声明 `terminal_resolve_aligned=true` 与
   `terminal_holds_business_truth=false`。
2. Terminal `TERMINAL_PATHS` 对齐 `/packages/actions/resolve` 与 `/surfaces`。
3. 无 Alembic；无 Marketplace 商业开通。
