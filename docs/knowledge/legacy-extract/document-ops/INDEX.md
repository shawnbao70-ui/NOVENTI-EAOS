## 使用约束

- 本索引登记的是 Legacy 观察事实，不是 EAOS 新设计。
- “存在页面/按钮”不等于“已生成可下载文件”；“保存路径”也不等于具备完整附件治理。
- `UNKNOWN` 表示只读检索范围内无法证明，不能据此推定功能存在或不存在。
