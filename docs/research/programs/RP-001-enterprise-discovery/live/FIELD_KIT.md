**Status:** **Open** · **0 Complete**

## Who

- [ ] Real observer, enterprise domain representative, facilitator, submitter, and source custodians.
- [ ] T3 witness/attestor if claimed; consent/recording basis for each participant.

## When / context

- [ ] Dated workshop/observation window with timezone and collection timestamps.
- [ ] Named enterprise site/tenant/cohort; included discovery domains and exclusions.
- [ ] Discovery instrument, worksheet, and dossier schema versions.

## Systems / artifacts

- [ ] Authorized read-only source inventory for profile, process, capability, organization, knowledge, and readiness evidence.
- [ ] Completed worksheets and versioned Discovery Dossier.
- [ ] Claim-to-source trace, data-gap/conflict/falsifier log, artifact IDs, integrity markers, and retention.

## Permissions / controls

- [ ] Approval for source review, interviews, screenshots/exports, and any AI-assisted facilitation.
- [ ] Data classification, redaction, controlled handles, retention/expiry, and registrar retrieval.
- [ ] Org≠Capability; discovery scores cannot authorize, grant, or execute.
