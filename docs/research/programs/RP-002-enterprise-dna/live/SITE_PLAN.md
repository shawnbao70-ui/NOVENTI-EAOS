# RP-002 Site Plan

**Program:** Enterprise DNA  
**Status:** **Open** · **0 Complete**  
**Assigned observer/site/window:** none / none / none  
**Access basis:** [SITE_ACCESS_PACK](../../../templates/SITE_ACCESS_PACK.md) · **Evidence review:** [ARTIFACT_ACCEPTANCE_RUBRIC](../../../templates/ARTIFACT_ACCEPTANCE_RUBRIC.md)

## Objective and boundary

Observe repeatability and constraint value of DX-01…08 using real, authorized dossier evidence. DNA is descriptive research, never individual profiling, HR judgment, permission, or grant input.

## Target observation points

1. Baseline scores trace to versioned RP-001 dossier sources rather than facilitator impression.
2. Independent raters interpret each axis consistently and record disagreement.
3. Missing/contradictory evidence changes confidence instead of being silently imputed.
4. A dated follow-up distinguishes stable traits from material context change.
5. Test/retest deltas have documented causes, confounders, and uncertainty.
6. DNA constraints improve recommendation fit or justify HOLD without predetermining outcomes.
7. Axis overlap/orthogonality issues are visible and challengeable.
8. No trait enters authorization, hiring, discipline, or grant logic.

## Required artifacts

1. Authorized versioned baseline dossier references.
2. Baseline DX-01…08 scorecards from each rater.
3. Measurement-guide/instrument version and scoring rationale.
4. Inter-rater comparison and disagreement-resolution record.
5. Dated follow-up dossier/scorecards and delta analysis.
6. Material-change/confounder and missing-evidence log.
7. Recommendation-fit/HOLD comparison with falsifiers.
8. Provenance, integrity, consent, retention, redaction, and custodian manifest.

## Dependency systems / contexts

1. Controlled RP-001 dossier store.
2. Survey/interview or evidence-collection system, if authorized.
3. Versioned DNA scoring workspace.
4. Recommendation/HOLD comparison workspace.
5. Secure retention and controlled-handle registry.

## Access and run sequence

1. Approve cohort, privacy basis, baseline/follow-up windows, raters, and retention duration.
2. Freeze instrument and source versions before baseline scoring.
3. Separate independent scoring from reconciliation and recommendation comparison.
4. Revoke access and reconcile all versions after each window.

## Risks / ethics

1. Cultural stereotyping or discriminatory classification; report evidence limits and prohibit individual use.
2. Sensitive workforce/survey disclosure; minimize, aggregate, and control access.
3. Rater anchoring and sponsor bias; preserve independent scores and dissent.
4. False stability caused by unchanged instruments but changed enterprise context; log confounders.
5. DNA score becoming permission or grant input; fail closed.
6. Follow-up pressure or consent withdrawal; honor withdrawal and record data disposition.

## Exit conditions

1. Stop if privacy/consent, source access, or follow-up basis is absent/revoked.
2. Stop if raters cannot verify dossier version, axis definition, or evidence timestamp.
3. Stop if scoring is requested for HR, discipline, authorization, or grant use.
4. Return incomplete if baseline/follow-up or comparison artifacts cannot be retained safely.
5. RP-002 remains Open; no site activity or rubric score alone marks Complete or flips a floor.
