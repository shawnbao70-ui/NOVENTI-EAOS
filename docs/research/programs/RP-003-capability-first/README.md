Define capability graphs as the primary lens for design, AI staffing, automation, and package adoption — deepening Cap≠Org into a consumable metamodel for RP-005/007.

## 2. Business Background

Organization Kernel models structure; industry still plans by department. Capability First is the missing operating lens between Discovery and Evolution.

## 3. Industry Problems

Departmental roadmap conflict; local AI optimization; package buying by politics; org reshuffles as fake progress; department names treated as capabilities.
