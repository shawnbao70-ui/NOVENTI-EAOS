# RP-004 Site Plan

**Program:** Organization Neutrality  
**Status:** **Open** · **0 Complete**  
**Assigned observers/sites/windows:** none / none / none  
**Access basis:** [SITE_ACCESS_PACK](../../../templates/SITE_ACCESS_PACK.md) · **Evidence review:** [ARTIFACT_ACCEPTANCE_RUBRIC](../../../templates/ARTIFACT_ACCEPTANCE_RUBRIC.md)

## Objective and boundary

Compare the same research instruments across at least two real organization forms to detect forced assumptions. The work evaluates instrument neutrality, not whether one organization is superior.

## Target observation points

1. Identical questions/instruments remain understandable across contrasting organization forms.
2. Decision rights can be represented without manager-only or hierarchy-only language.
3. Capability ownership remains separate from organization structure and Permission.
4. Matrix, council, multi-entity, network, and shop-floor patterns can express approvals and accountability.
5. Instrument scoring does not penalize non-default organization forms.
6. Forced-assumption defects are reproducible and tied to exact language/fields.
7. Remediation preserves meaning across both contexts.
8. Cross-jurisdiction/cultural differences are recorded without ranking or stereotyping.

## Required artifacts

1. Dated authorized context profile for each organization form.
2. Shared instrument/checklist and version record.
3. Completed neutrality audit for each context.
4. Comparable decision-right/capability-ownership examples.
5. Redacted forced-assumption defect excerpts.
6. Cross-context comparison matrix.
7. Remediation proposal and re-test record.
8. Exceptions, dissent, falsifiers, provenance, retention, and access manifest.

## Dependency systems / contexts

1. Organization/decision-right reference source for context A.
2. Organization/decision-right reference source for context B.
3. Shared research instrument repository.
4. Workflow/approval or UX language sample repository.
5. Secure cross-context comparison workspace.

## Access and run sequence

1. Obtain separate approvals, consent, data-sharing terms, and windows for every context.
2. Freeze the shared instrument before either observation.
3. Apply independently, then compare defects in a controlled workspace.
4. Complete context-specific redaction and revoke cross-entity access on exit.

## Risks / ethics

1. Treating organization difference as immaturity; prohibit ranking unsupported by research purpose.
2. Cultural or jurisdictional stereotyping; use evidence-specific language and local review.
3. Cross-entity confidentiality leakage; segregate raw artifacts and compare redacted extracts.
4. Decision-right examples exposing individuals or disputes; minimize identity and sensitive content.
5. Organization shape interpreted as Permission/grant; fail closed.
6. Remediation drifting into Const/BP or implementation change; keep proposal-only.

## Exit conditions

1. Stop if either context lacks independent access/consent or comparable scope.
2. Stop if raw cross-entity data cannot remain segregated.
3. Stop if the exercise is redirected to rank organizations or evaluate individuals.
4. Return incomplete if common instrument/version or defect trace is missing.
5. RP-004 remains Open; comparison alone cannot mark Complete, Promote, or flip a floor.
