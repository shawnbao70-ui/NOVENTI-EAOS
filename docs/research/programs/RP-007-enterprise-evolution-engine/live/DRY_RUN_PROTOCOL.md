# RP-007 Dry-Run Protocol

**Mode:** synthetic  
**Tier:** T1 only  
**Registry effect:** none — RP-007 remains **Open**  

Purpose: rehearse advisory evolution and HOLD handling without a live dossier or decision context. Apply the [live/synthetic fence](../../../templates/LIVE_VS_SYNTHETIC_FENCE.md).

## Desktop exercise

1. Allocate `DR-YYYYMMDD-RP-007-##`; all decision and observer roles are simulated.
2. Generate a fictitious frozen dossier and trigger set with missing/conflicting evidence.
3. Run Evaluate → Trigger → Recommend → Explain/Simulate → Human Decide → Learn.
4. Exercise every recommendation class and deliberate should-HOLD cases.
5. Role-play blind usefulness scoring and accept/defer/reject decisions; label them simulated.
6. Verify zero side effects, Brain execute, Twin authorize, Permission bypass, or workflow commit.
7. Close as `Dry-run closed — T1` and retain gap/falsifier records.

## Fake-data boundary

- All enterprises, dossiers, metrics, decisions, recommendations, and outcomes are generated.
- No real strategy, investment, worker, production, tenant, or decision record.
- Label ledgers and simulations `SYNTHETIC / NOT LIVE EVIDENCE`.

## Prohibited outcome

Synthetic recommendation usefulness or realistic human role-play cannot be marked Complete or treated as live decision-quality evidence.

## Exit conditions

- Recommendation/HOLD, provenance, and `execution_authority=none` paths were exercised; gaps logged.
- Real dossier or decision data triggers stop/isolation and a new authorized LC intake.
- Registry remains **0 Complete** and RP-007 remains **Open**.
